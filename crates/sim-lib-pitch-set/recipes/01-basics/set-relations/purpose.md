# Canonical Pitch-Set Relations (descriptor)

`analyze_set_relations` compares phase-08 conventional forms while retaining
the exact source and target masks. Its report distinguishes exact Tn and TnI
operators from transposition-only and transposition/inversion prime-form
equivalence, and separately records inclusion, common tones, exact and
class-equivalent complements, interval vectors, and Z-relation.

Symmetric sets retain every matching operator. Numeric `PitchClassMask`
normalization remains a separate compatibility identity and is never used as a
substitute for conventional set classification.

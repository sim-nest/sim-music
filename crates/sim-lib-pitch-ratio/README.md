# sim-lib-pitch-ratio

Exact positive musical ratio intervals with octave equivalence, prime-limit
factor vectors, finite rank/unrank, cents/error helpers, and bounded
approximation search. It also builds root-declared chord interval matrices,
coverage summaries, generalized-mean chord costs, and lazy cycle-safe ratio
relation trees.

Use this crate when a pitch interval must keep rational identity instead of
collapsing to equal-tempered semitones or floating frequency ratios.

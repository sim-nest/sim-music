# Inspectable Learned Transition Score (descriptor)

Chord/key states adapt the generic `sim-lib-numbers-stats` finite Markov model.
The model retains exact counts, additive smoothing, held-out likelihood, stable
serialization, and the generated CC0 fixture hash. A named learned-transition
metric contributes negative log probability only in `HarmonyRuleSet.soft`;
declared hard rules remain the sole legality gate and keep independent evidence.
